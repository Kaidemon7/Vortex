.NET Runtime Note
=================
UABE and some tools require .NET to run on Linux.
On Arch Linux, install: sudo pacman -S dotnet-runtime dotnet-sdk
Or use Wine to run the Windows versions of these tools.

The official .NET installer URL for Windows tools:
https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/runtime-6.0.36-windows-x64-installer

For Linux native .NET:
sudo pacman -S dotnet-runtime-6.0
